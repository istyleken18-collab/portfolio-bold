# AI開発ポートフォリオ — Bold Industrial Impact

生成AIを使って制作したWebサイト・業務システム・ゲームの実績をまとめた、石原 健のポートフォリオサイトです。

公開URL: https://istyleken18-collab.github.io/portfolio-bold/

## 構成

| パス | 内容 |
|---|---|
| `index.html` | サイト本体。ビルド不要の静的HTML1ファイル |
| `images/hero.webp` | ヒーロー画像。GPT Image 2 で生成（2048×1152） |
| `images/bg.webp` | 背景テクスチャ。GPT Image 2 で生成（2048×2048） |
| `images/*.jpg` | 各実績のスクリーンショット |

外部のCDN・フォント・スクリプトを読み込まないため、`index.html` をブラウザで開くだけで動作します。

## デザイン

"Bold Industrial Impact" — 黒地 `#0a0a0a` に蛍光イエローグリーン `#d0ff00`。極太ゴシックを字間マイナスで組み、角丸を使わず、影はぼかし0のオフセットのみ。アニメーションは 0.1秒・`steps(2, end)` で段階的に切り替えます。

色とサイズは `index.html` 冒頭の CSS 変数（`:root`）にまとめてあります。

## 実績の追加・編集

`index.html` 内の `WORKS` 配列に1件ずつ定義しています。

```js
{ name:"作品名", cat:"カテゴリ",
  img:"images/xxx.jpg",   // 画像が無い場合は null
  desc:"一言説明",
  problem:"課題",
  made:"つくったもの",
  ai:"使ったAI", time:"制作時間",
  status:"進行中" }        // 省略可
```

`cat` に書いた値がそのまま絞り込みタグになります。画像は 4:3（推奨 1200×900px）で用意するとグリッドが揃います。

## 社長ダッシュボード（`ops/`）

`ops/index.html` は、携帯から片手で使う業務用の画面です。ポートフォリオ本体とは独立していて、`index.html` には影響しません。

追うのは金額の推移ではなく、**反響 → 追客 → 案内 → 申込 → 契約 → 引渡し → アフター** のどこで案件が止まっているかです。

| タブ | 役割 |
|---|---|
| 今日 | 放置している案件・期限が来た行動・今月のアフター対象を上から順に |
| 案件 | 売却／購入／賃貸／仕入れの一覧。「今日 接触」1タップで最終接触日を更新 |
| アフター | 引渡し済みの一覧。点検時期・保証満了・記念日を自動算出 |
| 担当 | 担当者ごとの持ち件数・放置件数・申込以降の件数 |
| 書き出し | Claude 相談用テキスト／JSON・CSV の書き出しと読み込み |

### 入力を増やさずに「見えていない」を埋める

手で入れるのは**お客様名・担当・ステージ・最終接触日**と**引渡し日**だけです。残りは計算で出します。

- **放置日数** — ステージごとに閾値を変えています（反響2日・申込3日・案内済5日・追客中7日・販売中14日など）。閾値は `index.html` 内の `STALE` を書き換えれば調整できます
- **アフターフォロー** — 引渡し日1つから、3ヶ月／6ヶ月／1年／2年／3年／5年点検、保証満了（5年）、引渡し記念日をすべて逆算。今月該当するものが「今日」タブの先頭に出ます

ステージと区分の定義は `KINDS`、点検の間隔は `MILESTONES` にまとめてあります。

### データの扱い

- 保存先は**この端末のブラウザの中（localStorage）だけ**です。サーバーには何も送りません
- **機種変更・ブラウザの履歴削除で消えます。** 週に一度は「書き出し」タブから JSON をコピーして、社内の安全な場所に保管してください
- 顧客名を扱うため、共用端末で使う場合はイニシャルや物件名での登録をおすすめします
- `robots` は `noindex, nofollow` を指定しています

### Claude との連携

localStorage は端末内にあるため、Claude から直接読むことはできません。
「書き出し」タブで相談用テキストを生成してコピーし、Claude に貼り付けてご相談ください。

将来、データを Google スプレッドシートに移せば、定期実行トリガーで毎朝自動的に
「放置案件・今月のアフター対象」を通知させることもできます。
